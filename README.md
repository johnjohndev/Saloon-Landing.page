## 📄 Sobre o projeto

Landing page visual do **Vivi Coiffeur**, feita com dados reais do salão — endereço, avaliações do Google e redes sociais. Um único arquivo, pronto pra abrir e usar.

## 📁 Estrutura

| Arquivo | Descrição |
|---|---|
| `index.html` | Site completo — HTML, CSS e imagens tudo em um único arquivo |

> 🖼️ As imagens estão embutidas direto no código (base64) — **não precisa de pasta extra**, só abrir o `index.html` no navegador.

## ✨ Seções do site

| | Seção | Conteúdo |
|---|---|---|
| 🏠 | Hero | Apresentação do salão |
| ⭐ | Barra de confiança | Nota do Google, endereço, telefone |
| 👩‍🎨 | Fundadora & CEO | Vivi Fagundes — formação e trajetória |
| ℹ️ | Sobre | História do salão |
| 💅 | Serviços | Coloração, corte, manicure, lavagem |
| 🖼️ | Galeria | Fotos do dia a dia |
| 💬 | Avaliações | Depoimentos reais do Google |
| 👥 | Equipe | Time do salão |
| 📍 | Contato | Endereço, horários, mapa e WhatsApp |

## ✅ Recursos funcionais

- 📱 Botão **"Agendar horário"** → abre o WhatsApp direto
- 🗺️ Mapa do Google incorporado
- 🔝 Clique na logo → volta ao topo da página
